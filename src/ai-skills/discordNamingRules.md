# Discord Naming Rules

Use naming that looks intentional, modern, and premium.

- Prefer short, readable names.
- Prefer kebab-case for channel keys and names when relevant.
- Keep naming consistent across the whole server.
- Use emojis sparingly and intentionally.
- Avoid visual spam.
- Use category names that are obvious and clean.
- Avoid overdecorated names unless the brand explicitly calls for it.
- If emojis are used, use them consistently for information architecture, not decoration only.
- Choose names that make sense to first-time members immediately.

Good patterns:
- welcome
- rules
- announcements
- general
- support
- tickets
- media
- resources
- scrims
- management
- partnerships
- creators
- premium-lounge

Avoid:
- vague names with no function
- duplicated names with tiny variations
- long titles that look like forum posts
