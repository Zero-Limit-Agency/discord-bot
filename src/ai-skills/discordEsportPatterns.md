# Discord Esport Patterns

For esports and competitive organizations, think operationally.

- Common role clusters:
  - owners / founders
  - admins
  - managers
  - coaches
  - analysts
  - players
  - substitutes
  - media
  - creators
  - partners / sponsors
  - community
- Common category clusters:
  - start / info
  - announcements
  - roster or players
  - scrims
  - match operations
  - media / content
  - support
  - community
  - staff
- Useful channels:
  - scrim-scheduling
  - match-planning
  - team-chat
  - vod-review
  - content-requests
  - partnership-ops
  - media-assets
  - community-updates
- Avoid creating fake “pro” structure if the brief does not justify it.
- If the org is small, compress the competitive structure while preserving professionalism.
