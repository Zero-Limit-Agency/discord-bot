# Discord Onboarding Patterns

Onboarding should reduce confusion and direct behavior early.

- Members should quickly find:
  - welcome
  - rules
  - how-to-use or start-here
  - links
  - announcements
- Onboarding channels should be readable before members explore the rest.
- Official info channels should not compete with general chatter.
- If role selection or orientation is implied, leave space for future onboarding workflows.
- For professional servers, onboarding should communicate structure, trust, and expected behavior.
- If the brief is minimal, still provide a coherent start sequence.
