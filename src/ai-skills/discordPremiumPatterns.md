# Discord Premium Patterns

Premium or VIP areas should feel exclusive and purposeful.

- Only create premium roles or channels if the business/community model suggests it.
- Premium should unlock meaningful access, not arbitrary clutter.
- Keep premium spaces tidy and clearly separated from public spaces.
- Common premium patterns:
  - premium-announcements
  - premium-chat
  - premium-resources
  - premium-voice
  - insider-updates
- Do not grant dangerous permissions to premium roles by default.
- Premium should be access-based, not moderation-based.
